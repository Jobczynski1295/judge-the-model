# Visual design notes

The GitHub Pages interface has been restyled with a restrained clinical-analytics aesthetic: deep navy navigation, muted teal highlights, off-white background, editorial typography, refined tables, and responsive layouts. No data, analysis, model settings, thresholds, or student decisions were changed.

## View locally

From the project root, run `bash run_app.sh` (or `npm start`) and open the local URL shown in the terminal. For GitHub Pages, publish from the repository root on the main branch.

## Customization

Edit `web/style.css`. The color variables at the top control the overall palette. The font uses Google Fonts when available and falls back to system fonts.
